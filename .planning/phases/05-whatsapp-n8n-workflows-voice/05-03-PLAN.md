<objective>
Update the 3 infrastructure n8n workflows (Coleta de eventos, Rotatividade Numero, identificaConexao) for multi-tenant operation, and create a Supabase migration to auto-duplicate configuracoes rows when a new expert is created.

Purpose: These workflows handle event collection, number rotation, and connection identification. Without expert_id scoping, number rotation would mix instances across experts, and event collection would process events for the wrong expert. The configuracoes duplication ensures new experts get default config values automatically (per D-09).

Output: 3 n8n workflows updated with expert_id resolution and filtering. Supabase migration updating admin_create_expert RPC to clone configuracoes.
</objective>

  -- Keep ALL existing parameters from the current function signature

)

LANGUAGE plpgsql
SECURITY DEFINER
AS $$
DECLARE
  -- Keep all existing variable declarations

  -- Keep ALL existing logic from the current function body

    SELECT v_expert_id, chave, valor, descricao

    WHERE expert_id = v_template_expert_id;
  END IF;

  -- Keep existing RETURN statement
END;
$$;
